# Конструктор драконов

Браузерный прототип: выбираем чешую, крылья и цвет, и дракон появляется на экране.

## Запуск

Откройте index.html в браузере. Сборка не нужна.

## Файлы

- index.html: разметка и элементы управления
- style.css: оформление, адаптивная верстка
- app.js: варианты чешуи, крыльев и цветов, отрисовка дракона в SVG
